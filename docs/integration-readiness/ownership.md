# Canonical ownership across Professional integrations

Growth Engine remains canonical for:
- Customer
- Reservation
- customer Payment
- Sales

Numeria Studio remains canonical for:
- Session
- Report
- calculation/appraisal result
- Numeria-specific snapshots

Velvet remains canonical for:
- professional memory
- Visit
- professional notes
- timeline

Integration projections and reference IDs do not transfer canonical ownership. Free/Pro features in Numeria Studio or Velvet must not duplicate Growth Engine's Reservation, Payment, or Sales records.
