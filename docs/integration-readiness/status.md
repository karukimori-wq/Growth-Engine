- Routine CI is separated from Cloudflare Production deployment.
- Numeria Studio server endpoint configuration is available through `NUMERIA_STUDIO_BASE_URL` with the previous ChatGPT Site endpoint retained as fallback.

No Business offering, entitlement, or D1 schema change is part of this readiness work.
